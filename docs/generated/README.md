# Generated References

Files in this directory are generated by `fast-agent-harness docsgen`.
Do not edit generated `.md` files by hand; change the source registry and run:

```sh
go run ./cmd/fast-agent-harness docsgen
```

Use `go run ./cmd/fast-agent-harness docsgen -check` for drift checks and
`-only <target>` for scoped regeneration during a focused change.

`fast-agent-harness doctor -docs` compares the running binary's registry-data
fingerprints with the `source-hash` footers in this directory. It proves
generated registry freshness, not prose freshness.
